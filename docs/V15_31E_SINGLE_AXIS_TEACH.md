# 选轴辅助示教（V15.31E）

目标是按住按钮手动改变一个关节，其他关节继续保持原角度；松键后选中关节锁定在新角度，再按需记录动作点。J2 两颗电机始终共同作为一个关节。当前首版只开放 J1–J5，J6 继续 POS_VEL HOLD，不称为完整六轴零重力。

## 启动与操作

控制机仓库根目录使用：

```bash
python3 tools/hardware/v15_31d_demo_session.py --execute --assisted-teach --supported --vertical --hands-off --clearance
```

这些现场标志用于启动时的真实状态。入口先复用原只读校验、当前实角 HOLD 和五级重力验证；界面在准备完成后开放操作，不自动执行往返动作。启动校准完成后，示教包保留该次校准结果，拖动期间不会伪造“无人接触”确认。会话最多 10 分钟，结束时制动/失能并保存终态。

在界面选择 J1–J5 中的一个关节，按住“辅助拖动”，手动沿该关节活动方向改变姿态。其他五个关节的目标不变。松开按钮后等待六轴静止 HOLD，再点击“记录实姿到动作组”，按原动作组流程保存。重放仍需原轨迹预演与授权。

单次按住的底层限额为 30 秒、相对按下起点 5°、速度 5°/秒；GUI 在 29 秒或 4.5°时提前请求保持。未选轴偏离原目标超过 0.25°时，也结束本次拖动。失焦、隐藏窗口和松键复用同一个释放处理；反馈或授权失效时不以旧角度生成新 HOLD，保留原 500 ms 命令租约制动与包到期策略。当前“关闭驱动力／拖动”仍是无补偿释放，与此按钮功能不同。

## 控制与证据

选中 GO 关节使用实时编码器角度作为随动参考，维持实时重力前馈、冻结已学习保持积分，并用编码器速度提供阻尼。J2 以双电机共同角度随动，保留差分同步控制。未选轴保持原位置控制、原目标及原力矩限制。J6 不切换 MIT，也不写入零位。

示教为独立的 1.4 协议与显式可选运行权限；未选域收到原 1.2 HOLD。普通设角、动作组、原严格精度配置和原无补偿拖动不变。交互会话报告中的 PASS 只表示启动和停止流程通过，实际手动拖动、未选轴保持及松键效果须依据单独的 teach_events 和实角样本核实。
